AI Desk Buddy – Project Introduction

In the modern era, technology is advancing rapidly, and artificial intelligence (AI) has become an integral part of daily life. Our project, AI Desk Buddy, is designed to function as an intelligent desktop assistant that can interact with users in real-time, answer questions, and provide useful information instantly. Unlike traditional digital assistants that require typing or touchscreen inputs, AI Desk Buddy focuses on voice-based interaction, making it convenient, hands-free, and user-friendly.

The system works by capturing the user’s voice through a high-quality microphone, which is connected to the Raspberry Pi 5, the central processing unit of the project. The voice input is then sent to the Gemini API, an advanced AI service that understands natural language, processes the query, and generates accurate and context-aware responses. Once the AI formulates an answer, it is played back to the user via a speaker system connected through an audio amplifier, ensuring clear and audible responses. This interaction happens almost instantly, providing a seamless conversational experience between the user and the AI Desk Buddy.

AI Desk Buddy is built using a combination of software and hardware components that work together to create an intelligent and interactive system. The Raspberry Pi 5 handles data processing, connectivity, and hardware control, while the Gemini API provides the intelligence behind the responses. The hardware components, including the microphone, audio amplifier, and speaker, allow smooth communication, making the device practical for desktop use. The system is compact, portable, and can be easily set up in offices, study areas, or personal workspaces.

One of the main advantages of AI Desk Buddy is its ability to provide instant, accurate answers without the need to manually search through multiple sources. It can help students with learning, assist professionals with quick information retrieval, and support everyday tasks that require fast and reliable answers. The project also demonstrates how AI can be effectively integrated with hardware to create smart, interactive devices that improve productivity and convenience.

In conclusion, AI Desk Buddy represents a step forward in bringing AI into everyday life. By combining voice recognition, advanced AI processing, and efficient hardware, it delivers a practical and intelligent desktop assistant capable of simplifying tasks, enhancing learning, and improving efficiency. This project not only highlights the capabilities of AI technology but also showcases its potential to transform ordinary desktops into smart, responsive workspaces.

def is_internet_available():
    """Checks if Mira is connected to the internet."""
    try:
        socket.create_connection(("8.8.8.8", 53), timeout=3)
        return True
    except OSError:
        return False

def get_adapter_address():
    try:
        output = subprocess.check_output(["hcitool", "dev"], text=True)
        for line in output.split("\n"):
            if "hci0" in line:
                return line.split("\t")[2].strip()
    except Exception as e:
        print(f"⚠️ Could not find adapter address: {e}")
    return None

def connect_to_wifi(ssid, password):
    print(f"📶 Attempting to connect to WiFi: '{ssid}'...")
    cmd = ["sudo", "nmcli", "device", "wifi", "connect", ssid, "password", password]
    try:
        result = subprocess.run(cmd, capture_output=True, text=True)
        if result.returncode == 0:
            print(f"✅ Success! Mira is now online on {ssid}.")
            return True
        else:
            print(f"❌ Failed: {result.stderr.strip()}")
            return False
    except Exception as e:
        print(f"❌ Error running nmcli: {e}")
        return False

def run_agent_loop():
    """Runs the PIN-less pairing agent."""
    dbus.mainloop.glib.DBusGMainLoop(set_as_default=True)
    bus = dbus.SystemBus()
    path = "/mira/agent"
    agent = MiraAgent(bus, path)
    obj = bus.get_object("org.bluez", "/org/bluez")
    manager = dbus.Interface(obj, "org.bluez.AgentManager1")
    try:
        manager.UnregisterAgent(path)
    except:
        pass
    manager.RegisterAgent(path, "NoInputNoOutput")
    manager.RequestDefaultAgent(path)
    print("🕵️‍♂️ Agent registered.")
    loop = GLib.MainLoop()
    loop.run()

def bluetooth_monitor():
    """Monitors internet and toggles Bluetooth visibility automatically."""
    bus = dbus.SystemBus()
    manager = dbus.Interface(bus.get_object("org.bluez", "/"), "org.freedesktop.DBus.ObjectManager")
    
    while True:
        try:
            objects = manager.GetManagedObjects()
            adapter_path = next((p for p, i in objects.items() if "org.bluez.Adapter1" in i), None)
            
            if adapter_path:
                props = dbus.Interface(bus.get_object("org.bluez", adapter_path), "org.freedesktop.DBus.Properties")
                adapter_props = props.GetAll("org.bluez.Adapter1")
                
                # Check for connected devices
                connected_count = 0
                for p, i in objects.items():
                    if "org.bluez.Device1" in i and i["org.bluez.Device1"].get("Connected", False):
                        connected_count += 1
                
                internet = is_internet_available()

                # LOGIC MATRIX
                if connected_count > 0:
                    # Device connected? Hide to secure channel.
                    if adapter_props.get("Discoverable"):
                        props.Set("org.bluez.Adapter1", "Discoverable", dbus.Boolean(False))
                        props.Set("org.bluez.Adapter1", "Pairable", dbus.Boolean(False))
                elif not internet:
                    # No Internet? Be visible!
                    if not adapter_props.get("Discoverable"):
                        print("🌐 Net Lost: Bluetooth Visible...")
                        props.Set("org.bluez.Adapter1", "Powered", dbus.Boolean(True))
                        props.Set("org.bluez.Adapter1", "Discoverable", dbus.Boolean(True))
                        props.Set("org.bluez.Adapter1", "Pairable", dbus.Boolean(True))
                else:
                    # Internet OK? Be hidden.
                    if adapter_props.get("Discoverable"):
                        print("🔒 Net OK: Bluetooth Hidden.")
                        props.Set("org.bluez.Adapter1", "Discoverable", dbus.Boolean(False))
                        props.Set("org.bluez.Adapter1", "Pairable", dbus.Boolean(False))
        except Exception as e:
            print(f"Monitor Error: {e}")
        
        time.sleep(5)

def start_rfcomm_server():
    """Listens for WiFi credentials via Bluetooth."""
    while True:
        adapter_addr = get_adapter_address()
        if not adapter_addr:
            time.sleep(5)
            continue
            
        try:
            server_sock = socket.socket(AF_BLUETOOTH, socket.SOCK_STREAM, BTPROTO_RFCOMM)
            server_sock.bind((adapter_addr, RFCOMM_PORT))
            server_sock.listen(1)
            print("📡 RFCOMM Server Listening...")
            
            while True:
                client_sock, address = server_sock.accept()
                print(f"🔗 Connected: {address}")
                try:
                    data = client_sock.recv(1024)
                    if data:
                        msg = data.decode('utf-8').strip()
                        if "," in msg:
                            ssid, pwd = msg.split(",", 1)
                            if connect_to_wifi(ssid.strip(), pwd.strip()):
                                client_sock.send("OK:Connected".encode('utf-8'))
                            else:
                                client_sock.send("ERR:Failed".encode('utf-8'))
                        else:
                            client_sock.send("ERR:Format".encode('utf-8'))
                except Exception as e:
                    print(f"Socket Error: {e}")
                finally:
                    client_sock.close()
        except Exception as e:
            print(f"Server Error: {e}")
            time.sleep(5)
        finally:
            try:
                server_sock.close()
            except:
                pass

async def tts_async(text, filename):
    communicate = edge_tts.Communicate(text=text, voice="hi-IN-SwaraNeural")
    await communicate.save(filename)

def speak(text, force_offline=False):
    """Speaks text. Uses cached file if available, otherwise generates it."""
    global current_state
    print(f"[AI]: {text}")

    # 1. Check if we have a saved file for this phrase
    cache_filename = SYSTEM_PHRASES.get(text)
    
    # If valid cache file exists, PLAY IT immediately and skip generation
    if cache_filename and os.path.exists(cache_filename):
        print(f"   -> Playing cached: {cache_filename}")
        subprocess.run(["mpg123", "-q", cache_filename])
        return

    # 2. If no cache, we must generate it.
    
    # OFFLINE CHECK: If we are offline and don't have a cache, fall back to espeak
    if force_offline or current_state == "no_internet" or not is_internet_available():
        try:
            subprocess.run(["espeak", "-v", "en+f2", "-s", "150", text])
        except Exception as e:
            print(f"Offline TTS Error: {e}")
        return

    # ONLINE GENERATION (edge_tts)
    if current_state != "no_internet":
        current_state = "speaking"
    
    # Determine filename: Use fixed name if system phrase, random UUID if dynamic
    if cache_filename:
        filename = cache_filename
        delete_after = False # Keep this file forever!
    else:
        filename = f"tts_{uuid.uuid4()}.mp3"
        delete_after = True  # Delete this file after playing
    
    try:
        asyncio.run(tts_async(text, filename))
        subprocess.run(["mpg123", "-q", filename])
    except Exception as e:
        print(f"TTS Error: {e}")
    finally:
        # Only delete if it's a temporary dynamic file
        if delete_after and os.path.exists(filename):
            os.remove(filename)
        
        if current_state == "speaking":
            current_state = "idle"

def listen_once(timeout=5, phrase_time=5):
    r = sr.Recognizer()
    r.energy_threshold = 50
    try:
        with sr.Microphone(device_index=MIC_DEVICE_INDEX, sample_rate=48000) as source:
            r.adjust_for_ambient_noise(source, duration=0.4)
            audio = r.listen(source, timeout=timeout, phrase_time_limit=phrase_time)
        return r.recognize_google(audio, language=LANG)
    except:
        return ""

def initialize_gemini():
    global current_key_index, chat
    while current_key_index < len(api_keys):
        try:
            genai.configure(api_key=api_keys[current_key_index])
            model = genai.GenerativeModel("models/gemini-2.5-flash")
            chat = model.start_chat()
            print(f"✅ Gemini Connected (Key {current_key_index})")
            return True
        except Exception as e:
            print(f"❌ Key {current_key_index} Error: {e}")
            current_key_index += 1
    return False

    global current_state
    print("✨ Touch!")
    
    # Trigger shy mode if idle/listening
    if current_state in ["idle", "listening"]:
        current_state = "shy"
        
        # Trigger the "Don't touch me" voice line in background
        # This uses the Cache system to be super fast!
        threading.Thread(target=lambda: speak("Don't touch me"), daemon=True).start()

try:

def main():
    global current_state, chat
    
    # 1. Start System Services (Bluetooth, OLED, etc.)
    subprocess.run(["sudo", "rfkill", "unblock", "bluetooth"])
    subprocess.run(["sudo", "sdptool", "add", "SP"])

    threading.Thread(target=oled_loop, daemon=True).start()
    threading.Thread(target=run_agent_loop, daemon=True).start()
    threading.Thread(target=bluetooth_monitor, daemon=True).start()
    threading.Thread(target=start_rfcomm_server, daemon=True).start()

    print("🚀 Mira System Started.")
    
    # ================= FLOWCHART LOGIC =================
    
    # Check: Is Internet Connected?
    if is_internet_available():
        # --- LEFT PATH: Internet Connected ---
        current_state = "net_connected"    # Display "Internet Connected"
        time.sleep(2)                      # Wait so you can read the text
        speak("Internet connected")
        
    else:
        # --- RIGHT PATH: Internet Not Connected ---
        current_state = "no_internet"      # Display "Internet Not Connected"
        time.sleep(2)
        speak("Internet not connected", force_offline=True)
        
        current_state = "bluetooth_wait"   # Display "Connect Bluetooth"
        speak("Bluetooth setup", force_offline=True)
        
        # Loop until WiFi connects
        print("⏳ Waiting for Internet via Bluetooth...")
        while not is_internet_available():
            time.sleep(2)
            
        # Rejoined Left Path
        current_state = "net_connected"
        time.sleep(2)
        speak("Internet connected")

    # --- Chatbot File (Initialize Brain) ---
    if not initialize_gemini():
        speak("I cannot connect to my brain.")

    # --- Final Step ---
    current_state = "ready"                # Display "I am ready"
    time.sleep(2)
    speak("I am ready")
    
    current_state = "idle"                 # Go to Idle Mode (Cute Face)

    # ================= END FLOWCHART =================

    # --- MAIN LOOP (Standard Features) ---
    while True:
        # Safety Check: Did internet drop while running?
        if not is_internet_available():
            current_state = "no_internet"
            speak("Internet lost", force_offline=True)
            while not is_internet_available():
                time.sleep(2)
            current_state = "idle"
            speak("Internet connected")
            continue

        # Chatbot Interaction Cycle
        try:
            if current_state == "shy":
                time.sleep(2)
                current_state = "idle"
                continue

            # Listen
            text = listen_once(timeout=3, phrase_time=5).lower()
            
            # Wake Word Check
            found_wake_word = next((w for w in WAKE_WORDS if w in text), None)
            
            if found_wake_word:
                parts = text.split(found_wake_word)
                question = parts[-1].strip() if len(parts) > 1 else ""
                
                if not question:
                    current_state = "listening"
                    speak("Yes?")
                    question = listen_once(timeout=6, phrase_time=6)
                
                if question:
                    current_state = "thinking"
                    try:
                        prompt = f"You are Mira. Max {MAX_WORDS} words: {question}"
                        response = chat.send_message(prompt)
                        current_state="speaking"
                        speak(response.text)
                    except Exception as e:
                        print(f"API Error: {e}")
                        speak("I am having trouble thinking.")
                        
        except Exception as e:
            print(f"Loop Error: {e}")
            time.sleep(1)

if __name__ == "__main__":
    main()

Components Used

The Raspberry Pi 5 is a powerful single-board computer that serves as the central processing unit for our AI Desk Buddy. It handles all data processing, voice input management, and communication with the Gemini AI API. With its compact size and high performance, it efficiently runs the software that converts user questions into intelligent responses. The Raspberry Pi 5 also manages hardware components like the microphone, audio amplifier, and speaker, making the desk buddy fully functional and responsive.

The Active Cooler is a small cooling fan used to regulate the temperature of the Raspberry Pi 5 in our AI Desk Buddy. It prevents overheating during extended use, ensuring stable performance while processing voice commands and interacting with the Gemini API. Its compact design fits neatly on the board without taking up much space. By maintaining optimal temperature, the active cooler helps the system run efficiently and reliably.

The INMP441 MEMS Microphone Module is a high-performance digital microphone used to capture voice commands for our AI Desk Buddy. It converts sound waves into digital signals that the Raspberry Pi 5 can process efficiently. Its compact size and low power consumption make it ideal for desktop applications. With clear and accurate audio capture, it ensures that the AI system receives precise input for generating intelligent responses.

The MAX98357 I2S Audio Amplifier is a compact digital audio amplifier module that delivers clear sound output for our AI Desk Buddy. It receives digital audio signals directly from the Raspberry Pi 5 via the I2S interface, eliminating the need for extra DACs. The module efficiently powers a speaker, allowing the AI to respond audibly to user queries. Its small size, high-quality audio, and low power consumption make it ideal for desktop voice-interactive applications.

The Speaker is used to deliver audible responses from the AI Desk Buddy, allowing users to hear answers clearly. It is connected to the MAX98357 I2S audio amplifier, which amplifies the digital audio signals from the Raspberry Pi 5. The speaker ensures that voice responses from the Gemini AI are clear and natural, enhancing user interaction. Its compact size makes it suitable for desktop use without occupying much space.

The OLED Display is used in our AI Desk Buddy to represent animated eyes, giving the device a more interactive and expressive appearance. It communicates with the Raspberry Pi 5 via I2C, allowing dynamic animations that reflect the system’s responses or listening status. The animated eyes enhance user engagement by providing a visual cue alongside the audible answers from the speaker. Its compact size, low power consumption, and high contrast make it ideal for desktop applications while adding a friendly and interactive element to the desk buddy.

The Servo Motor is used in our AI Desk Buddy to control head movements, making the device more interactive and lifelike. This movement, combined with the animated eyes on the OLED display, enhances the overall user experience by providing visual feedback and personality. Working of AI Desk Buddy (Voice-Based Chatbot)

AI Desk Buddy is a voice-based conversational assistant designed to interact with users in a natural and friendly manner. The system works by combining speech recognition, artificial intelligence, and text-to-speech technologies to enable real-time communication between the user and the assistant.

The working process begins when the system is initialized. During startup, the Gemini AI model is configured using the google.generativeai library, which connects the application to the Gemini API. A predefined conversation context is set so that the AI responds like a close friend, using simple language, emotional tone, and short replies.

Once initialized, the system continuously listens for user input through a microphone. The speech_recognition library is used to capture the user’s voice and convert spoken audio into text. This step allows the system to understand what the user is saying. Audio sensitivity parameters are adjusted to reduce background noise and improve accuracy.

After the user’s voice is successfully converted into text, the recognized text is sent to the Gemini AI model. The Gemini API processes the input using natural language processing and generates a meaningful, context-aware response. The response length is limited to maintain clarity and ensure a smooth conversational experience.

When the AI response is received as text, it is converted into speech using the edge_tts library. This library generates natural-sounding audio using a neural voice, with controlled speech rate and pitch to sound friendly and human-like. The generated speech is saved temporarily as an audio file.

The audio output is then played through the system’s speaker using a media playback process handled by the subprocess and threading libraries. This ensures that audio playback runs smoothly without blocking the main program. After playback, the temporary audio file is deleted to keep the system efficient.

This entire cycle—listening, processing, responding, and speaking—runs continuously in a loop, allowing real-time interaction. By integrating speech recognition, cloud-based AI processing, and text-to-speech output, AI Desk Buddy provides a hands-free, responsive, and engaging conversational assistant suitable for everyday desktop use.
